* :productname:`OXID Security Modul` 2.0

  Schützen Sie mit CAPTCHA-Schutz die Formularbereiche Ihres OXID eShops effektiv vor automatisierten Bot-Angriffen.

  Weitere Informationen finden Sie in der Dokumentation zum `OXID Security Modul <https://docs.oxid-esales.com/modules/security/de/2.0/releases/security-module-200.html>`_.


* :productname:`Consistency Check Tool` 1.0

  Optimieren Sie die Datenpflege, indem Sie ungenutzte Bilddateien und fehlende Zuordnungen identifizieren.

  For more information, see `OXID eShop Consistency Check Component <https://github.com/OXID-eSales/consistency-check-tool/tree/v1.0.0>`_.

  Ermöglichen Sie es dem Chefeinkäufer, ein sekundäres Budget festzulegen, sodass Einkäufer kleinere Bestellungen direkt und ohne Genehmigungsprozess tätigen können – und reduzieren Sie so den internen Verwaltungsaufwand.
