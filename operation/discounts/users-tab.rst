Restricting Discounts to Users or Groups
========================================

Limit the scope of a discount to individual users, user groups, or a combination of both.

This allows you to offer special prices to specific customers in your online shop.

If no users or user groups are assigned to the discount, it applies to all customers.

If both users and user groups are assigned, the discount applies only to customers who belong to both categories.

|procedure|

1. Choose :menuselection:`Shop Settings --> Discounts`.
#. Choose an existing discount or create a new one.
#. Enter a meaningful name for the discount and define the price reduction.
#. In the :guilabel:`Users` tab, choose the :guilabel:`Assign Users` or :guilabel:`Assign User Groups` button.
#. Drag and drop the desired users or user groups into the right-hand list of the assignment window.
#. Close the assignment window.
#. Save the changes.

|result|

The discount is applied only to the assigned users and user groups.
