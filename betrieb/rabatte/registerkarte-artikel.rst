Rabatte auf Kategorien oder Artikel begrenzen
=============================================

Begrenzen Sie einen Rabatt auf einzelne Artikel, eine Kategorie oder mehrere Kategorien.

Damit können Sie gezielt einzelne Artikel oder ganze Warengruppen in einer Rabattaktion bewerben.

|procedure|

1. Wählen Sie :menuselection:`Shopeinstellungen --> Rabatte`.
#. Wählen Sie einen bestehenden Rabatt oder erstellen Sie einen neuen.
#. Geben Sie dem Rabatt einen aussagekräftigen Namen und legen Sie fest, um wie viel der reguläre Preis reduziert wird.
#. Wählen Sie auf der Registerkarte :guilabel:`Artikel` die Schaltfläche :guilabel:`Artikel zuordnen` oder :guilabel:`Kategorien zuordnen`.
#. Ziehen Sie die gewünschten Artikel oder Kategorien per Drag & Drop in die rechte Liste des Zuordnungsfensters.
#. Schließen Sie das Zuordnungsfenster.
#. Speichern Sie die Änderungen.

|result|

Der Rabatt wird nur auf die zugeordneten Artikel oder Kategorien angewendet.

Wenn keine Benutzer oder Benutzergruppen zugewiesen sind, gilt der Rabatt für alle Kunden des Ihres OXID eShops.
